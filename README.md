# Planner — Günün, cebinde ✨

![Planner](screenshots/og.png)

Her sabah Telegram'dan "bugün bunları yapmalısın" diye yazan, teslim tarihleri yaklaşınca uyaran ve **Gemini** ile günümü planlayan kişisel ajandam.

**[✨ Canlı demoyu dene](demo.html)**

## Özellikler
- ☀️ Telegram'dan sabah brifingi, saatli hatırlatmalar, akşam ve haftalık özet
- 🤖 Gemini ile günlük plan, büyük görevleri alt adımlara bölme, haftalık değerlendirme
- 💬 Bota mesaj yazarak görev ekleme ("Diş hekimi cuma 15:30 #Sağlık !")
- 📅 Takvim, tekrarlayan görevler, alt adımlar, öncelik ve kategoriler
- 🔥 Alışkanlık takibi (seri, 30 günlük ısı haritası), istatistikler, odak zamanlayıcısı
- 📱 Telefona simgeyle yüklenen uygulama (PWA), açık/koyu tema

## Teknoloji
Google Apps Script (sunucu) · Google Sheets (veri) · Telegram Bot API · Gemini API · HTML/CSS/JS · GitHub Pages
